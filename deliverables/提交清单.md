## 提交前必须替换

1. **团队名称**：白皮书封面、PPT 第 16 页。
2. **成员姓名/专业/履历**：白皮书“五、团队介绍”表格；PPT 第 16 页。
3. **项目名称**：如需调整，统一替换“织序 AgentLoom”。
4. **演示视频**：按 `docs/demo-script.md` 录制，建议 3 分钟以内。
5. **证明资料**：学生身份证明、项目资质、应用推广证明等，按通知要求附上。

## 命名格式

按大赛通知，提交时命名格式为：

```text
【赛题名称（写赛题一/二/三即可）+队伍名称+项目名称】
```

例如：

```text
赛题一+队伍名称+织序AgentLoom-项目白皮书.docx
赛题一+队伍名称+织序AgentLoom-项目介绍.pptx
赛题一+队伍名称+织序AgentLoom-演示视频.mp4
```

## 数据口径

- 当前演示知识库为**模拟整理资料**，界面与文档均已标注，不构成真实投资依据。
- Mock 模式的核查分、Token、耗时来自真实运行，但 Token/成本为模拟计量。
- Live 模式需在设置中填入 DeepSeek API Key，或使用环境变量 `AGENTLOOM_API_KEY`。
- 白皮书中的市场测算为**早期假设**，需在试点中校验。

## 一键重置

```bash
pnpm reset
```

会删除 `data/agentloom.db` 并重新写入 6 篇资料、8 个 Agent、10 个节点。
